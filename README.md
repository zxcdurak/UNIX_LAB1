# build.sh

POSIX-совместимый shell-скрипт для сборки одного исходного файла — программы на C/C++ (`gcc`/`g++`) или документа TeX (`pdflatex`).

## Использование

```sh
./build.sh path/to/source.c
```

## Как это работает

1. Ищет в исходном файле комментарий `Output: имя_файла` и берёт из него имя результата.
2. Создаёт временный каталог через `mktemp -d`.
3. Собирает файл внутри этого каталога (тип определяется по расширению: `.c`, `.cpp`/`.cc`/`.cxx`, `.tex`).
4. Копирует готовый результат рядом с исходником под именем из `Output:`.
5. Временный каталог удаляется при любом исходе — успехе, ошибке сборки или получении сигнала (`INT`, `TERM`, `HUP`, `QUIT`, `PIPE`).

## Коды возврата

| Код | Причина |
|---|---|
| 0 | Сборка успешна |
| 1 | Неверные аргументы / файл не найден или не читается / не удалось создать временный каталог |
| 2 | Ошибка компиляции |
| 3 | Комментарий `Output:` не найден |
| 4 | Неизвестный тип исходного файла |
